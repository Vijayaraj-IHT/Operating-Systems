# 💻 Operating Systems Laboratory

Lab programs exploring core operating-system concepts — process management, scheduling, synchronization, memory management, and file systems.

---

## 📖 Topics

- **Process & thread management** — creation, lifecycle
- **CPU scheduling** — FCFS, SJF, Round Robin, Priority
- **Process synchronization** — semaphores, classic problems (producer–consumer, readers–writers, dining philosophers)
- **Deadlock** — detection & avoidance (Banker's algorithm)
- **Memory management** — paging, segmentation, page-replacement (FIFO, LRU, Optimal)
- **File allocation & disk scheduling** — FCFS, SSTF, SCAN, C-SCAN

## 🛠️ Language

Implemented primarily in **C** (Linux / GCC).

```bash
gcc program.c -o program && ./program
```

> Programs are being added as the lab progresses.
